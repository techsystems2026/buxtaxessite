# 🚀 Инструкция по публикации на Render.com

Этот проект подготовлен для развертывания на Render.com с использованием Blueprint (render.yaml).

## 🛠 Предварительные требования
1. Аккаунт на [Render.com](https://render.com).
2. Подключенный репозиторий GitHub/GitLab.

## 🏁 Шаги для публикации

1. **Создайте новый Blueprint**:
   - В панели Render выберите **New** -> **Blueprint**.
   - Выберите этот репозиторий.
2. **Настройка переменных**:
   - Render автоматически создаст базу данных PostgreSQL и веб-сервис.
   - **ВАЖНО**: После первого деплоя зайдите в настройки Environment вашего Web Service в панели Render и обновите переменную `NEXT_PUBLIC_URL`, указав там реальный URL вашего сайта (например, `https://bux-taxes-web.onrender.com`).
3. **Готово!**:
   - После завершения сборки ваш сайт будет доступен.

## 🐳 Локальный запуск (Docker)

Если вы хотите запустить проект локально в Docker:
```bash
docker-compose up --build
```
Сайт будет доступен по адресу [http://localhost:3000](http://localhost:3000).

## 📁 Структура проекта
- `/admin` — Админ-панель Payload CMS.
- `/services/[slug]` — Страницы услуг.
- `/contacts` — Форма обратной связи.

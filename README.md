# 🎨 1. Логотип BUX&TAXES

**Идея логотипа:**

* Символизирует бухгалтерию, налоги и надёжность
* Современный и минималистичный стиль
* Можно использовать сочетание букв **B&T** или полный текст **BUX&TAXES**
* Цвета: тёмно-синий (#0F172A) + зелёный акцент (#059669)

**Варианты логотипа:**

1. **Текстовый логотип**

```
BUX&TAXES
```

* Шрифт: Inter Bold или Manrope Bold
* Акцент: символ & зелёный, остальное тёмно-синее

2. **Логотип с иконкой**

* Иконка: стилизованный калькулятор, график, документ или монета
* Текст: BUX&TAXES справа
* Цвета: иконка зелёная, текст тёмно-синий

3. **Монограмма B&T**

* Инициалы B&T переплетены в минималистичном стиле
* Можно использовать как фавикон и для соцсетей
